# БизнесПомощник

## Установка на Windows

**[Скачать БизнесПомощник для Windows — BizAgent-Setup.exe (версия 2.0.0, 66 МБ)](https://github.com/andreimikhnovets/bizagent/releases/download/v2.0.0/BizAgent-Setup.exe)**

Вам понадобится компьютер с 64-разрядной Windows 10 или 11 и интернет для первого запуска. Оставьте не менее 13 ГиБ свободного места после установки. Для работы ИИ рекомендуется 16 ГБ оперативной памяти.

1. **Установите программу.** Нажмите ссылку выше, откройте скачанный файл двойным щелчком и следуйте подсказкам мастера. Все необходимые компоненты устанавливаются автоматически.
2. **Откройте «БизнесПомощник».** Дважды щёлкните по ярлыку на рабочем столе. Появится текстовое окно с ходом загрузки. Оставьте его открытым: при первом запуске программа скачивает компоненты ИИ объёмом в несколько гигабайт.
3. **Задайте пароль.** Когда в этом окне появится приглашение, придумайте пароль длиной от 12 до 128 символов, нажмите **Enter** и введите его ещё раз. При вводе символы пароля скрыты. Дождитесь окончания загрузки модели — страница входа откроется в браузере автоматически.
4. **Войдите в приложение.** В поле электронной почты введите `owner@uyut.by`, а в поле пароля — пароль из предыдущего шага. Для знакомства откройте **«Обзор»**: там уже есть показатели учебной компании. Затем откройте чат и задайте вопрос, например «Какая выручка за прошлый месяц?». Первый ответ ИИ может занять несколько минут.

**После работы** нажмите **Enter** в текстовом окне программы, когда увидите приглашение для остановки. В следующий раз откройте тот же ярлык и войдите с прежним паролем. Данные сохраняются, скачанная модель используется повторно.

Если загрузка прервалась, проверьте интернет и свободное место, затем снова откройте ярлык. Установщик без цифровой подписи, поэтому Windows может показать предупреждение SmartScreen. [Страница выпуска с контрольной суммой файла](https://github.com/andreimikhnovets/bizagent/releases/tag/v2.0.0)

Для удаления откройте раздел «Приложения» в параметрах Windows. Данные хранятся в папке `%LOCALAPPDATA%\BizAgent\data`.

## Как пользоваться

- В разделе обзора отображаются показатели компании. В аналитике выберите нужный период.
- В заказах найдите продажу и откройте её состав. Для загрузки продаж скачайте шаблон CSV, заполните его, просмотрите результат проверки и подтвердите импорт. Загруженные партии доступны в истории.
- В чате задайте вопрос или приложите документ. Проверьте предложенное ассистентом действие перед подтверждением.
- В закупках можно составить заказ поставщику. В разделе сотрудников владелец управляет доступом и ролями.
